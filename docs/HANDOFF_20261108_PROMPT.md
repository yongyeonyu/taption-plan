## 함정

- 맥 메모리·디스크가 빠듯합니다. 시뮬레이터는 쓰고 끄고, DerivedData는 지웁니다. 다른 세션 시뮬레이터는 건드리지 않습니다.
- 시험 러너가 연결 전에 반복해서 멈추면 그 시뮬레이터를 `xcrun simctl erase`합니다.
- `MapHomeVectorRouteRenderingTests`·`CategoryCacheBenchmarkTests`는 부하가 높으면 실패합니다. 단독 재실행으로 확인합니다.
- 에이전트를 쓸 때 공유 스크래치패드 파일 이름이 겹치면 서로 덮어씁니다. 요청별 접두어를 씁니다. 작업 트리는 옛 커밋에서 갈라질 수 있어 합친 뒤 전체 시험이 필요합니다.
- `release.sh`는 깨끗한 작업 트리가 필요하고 빌드 번호 변경은 직접 커밋합니다. 외부 그룹 제출은 스크립트에 없고 `scripts/testflight/asc.py`의 API로 그룹 연결 뒤 `betaAppReviewSubmissions`를 보냅니다.
- 시뮬레이터에는 한글을 입력할 수 없습니다. 실제 Apple 검색 결과는 맥에서 MapKit으로 재거나 기기에서 봅니다.
- 공개 저장소에는 메일, 계정 이름이 든 주소, 공개 링크를 적지 않습니다.
