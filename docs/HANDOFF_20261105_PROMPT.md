## 함정

- 동결 파일은 커지면 CI 구조 점검이 실패합니다. 기능은 새 파일에 넣고 커밋 전에 `--check`를 돌립니다.
- 빌드 번호는 `release.sh`가 올리지만 커밋은 직접 해야 합니다. `release.sh`는 깨끗한 작업 트리를 요구합니다.
- 업로드 중에는 소스를 고치지 않습니다.
- `-debugViewportWidth` 값이 시뮬레이터 설정에 남을 수 있습니다. 넓은 화면 UI 시험은 매번 값을 줍니다.
- 튜토리얼 UI 시험은 시험마다 새 시뮬레이터가 필요합니다. 같은 시뮬레이터에서 이어 돌리면 실패합니다.
- watchOS 시뮬레이터 런타임이 없어 Watch 화면은 빌드로만 확인됩니다.
- 공개 저장소에는 메일, 계정 이름이 든 주소, 공개 링크를 적지 않습니다.
