## 1. 대표 확인 목록 (아침)

1. 백업 복원: 옛 파일 44개를 지워 아이폰 18이 올린 백업은 13개(2026-05~11, 미래 5개 달, 설정)가 남았다. 아이폰 11에서 비밀번호를 넣고 복원한다. 새 빌드로 다시 백업하면 미래 달은 계획이 있는 달만, 건강 표본만 있던 달은 빼고 올라가는지 본다.
2. 가계부: 지도 왼쪽 위 여행 단추 옆 ₩ → 기록 넣기·고치기·지우기, 예산, 오늘 손익, 정산. 여행 모드에서 열면 「이 여행」 합계가 보인다.
3. 결제 문자: 실제 카드 문자 5건을 복사해 가계부의 「붙여넣기」로 넣는다. 단축어 앱 → 자동화 → 메시지를 받을 때 → 「결제 문자 넣기」를 걸어 본다. 읽지 못한 형식이 있으면 그 글을 보내 주면 맞춘다(개인 정보는 가려서).
4. 영수증 사진 하나로 합계·가게 이름이 채워지는지 본다.
5. 여행 미리보기: 빠듯한 이동·항공편 도착 뒤 경고가 보이는지, 여행 지도의 비행 구간이 곡선으로 그려지는지 본다.
6. 앞에서 남은 것: 16:43~19:57 이동(MOV1110A01), 수면(SLP1111A01), Claude·ChatGPT 단계별 연결 끝까지, Cue 실제 등록.

## 2. 대표 판단이 필요한 것 (밤사이 건너뜀)

- 가계부를 AI 하루 기록에 싣는 방식: 지금은 공유 수준이 「보내지 않음」이 아니면 가계부 내용·금액이 실린다(대표 결정대로). 이미 연결한 AI에도 이번 빌드부터 실리므로, 따로 켜는 스위치를 둘지 정해야 한다.
- 영수증: 계획은 「앱을 열 때 새 사진을 자동으로 읽기」였다. 사진 권한·배터리·오인식 부담 때문에 「사용자가 고른 사진만」으로 바꿨다(추천안). 자동이 필요하면 다시 지시해 주면 된다.
- 밤 전 목록 그대로: APNs 푸시 키, Cloudflare 유료 전환, IAP·심사, 외부 테스터, 웹사이트, 번역 사람 검수, 지메일 권한 심사.
