## 2단계 · 여행 자동화 화면 연결 (TAU1110A01, 선행 없음)

1. 항공편 대권 선: 여행 계획 형식에 출발 공항 좌표를 더하거나 공항 좌표표를 내장 → 여행 지도에 선.
2. 미리보기 이동 시간 경고: Apple 길찾기 시간에 20% 마진, 항공편 뒤에는 공항 대기 블록. 나라 코드를 일정에 더해야 한다.
3. 요금 계산 호출부: 대중교통 구간 기록에 요금 표시(지역·수단 판별 필요). 대구 버스 요금, 미확인 값 2개 확인.
4. 머문 곳 이름 자동 채움: 중계 서버에 카카오 반경(카테고리) 검색 추가 → 자동 기록의 이름 후보. 자동 판정 근거를 남기고 사용자 수정과 구분한다.

정할 것: 카카오 대중교통 경로 제공 여부 확인(안 되면 정류장 순서 데이터만), 공공데이터 API 한도 확인.

## 3단계 · 가계부 (LED1110A01, 선행: 1단계 출시)

1. 별도 SQLite DB와 스키마: 지출·수입·예산, 대분류·세부 항목, 장소, 결제한 사람, 통화와 환율. 기존 백업에 같은 6자리 비밀번호로 포함(옛 백업 읽기 유지).
2. 왼쪽 위 모드 아이콘 옆 `$` → 표 화면. 일상 가계부가 기본, 여행 연결은 선택.
3. 환율: 중계 서버가 하루 한 번 공개 환율, 수동 입력 가능.
4. 예산: 월·분류별, 여행별(통화별), 주간.
5. 단체 정산: 연락처에서 사람 고르기, 최소 송금 명세.
6. AI 명령: 지출 추가·읽기.
7. 급여 연동(세후): 오늘 손익, 잠금 화면 한 줄, 지출을 근무 시간으로, 하루 끝 「수입·근무(예상)」.

## 4단계 · 결제 감지 (TAU1110A01 4장, 선행: 3단계)

1. 결제 문자: 클립보드 배너 + 단축어 App Intent 「결제 문자 넣기」(iOS는 앱이 문자를 직접 못 읽는다). 카드 문자 파서, 실제 문자 5건으로 검증.
2. 영수증·스크린샷 글자 인식: 기기 안 Vision, 새 사진만(앱을 열 때 확실, 백그라운드는 iOS가 허락할 때), 계좌 내역/영수증 3중 구분, 글만 큐에 두고 원본은 버림.
3. 보류: 지메일 승인 메일(구글 제한 권한 심사 필요), 화면 기록 프레임 인식.
