试着走一遍

  • 底部三格是导航,不是工具箱。切换视图不会丢失日期。
  • 点 타임라인 → 点任意色块 → 编辑器从 1 层 打开。
  • 点 ‹ 时间轴 返回 → 那个色块仍然选中,滚动位置也还在。
  • 点 기록 → 直接看到本周。这一步现在完全不可达。
  • 左上 ☰ 是抽屉,只放配置与例行,不放浏览。
  • 地图上的权限卡是状态,不是弹窗。关掉它,地图就是空的——但你已经知道为什么。
