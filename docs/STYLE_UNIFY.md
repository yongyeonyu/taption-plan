# 앱 전체 스타일 통일 — 조사와 순서 (STY1116A01)

대표 지시(2026-11-16): 「하단 메뉴의 위치와 모양은 유지해야 하고 앱 전체 스타일을 통일하자」.

기준은 `docs/DESIGN_SYSTEM.md`(§2.3 간격 2pt 격자, §2.4 모서리, §5.3 누르는 영역 44pt)와 코드의 `TaptionCorner`(대표 결정 UIR1111A01: 작은 단추·칩 8, 카드·띠 12, 묶음 패널 16, 시트 24)다. 두 자료의 모서리 단계가 다르므로(문서는 4·8·12·16·22, 코드는 8·12·16·24) 나중에 정한 `TaptionCorner`를 따른다.

건드리지 않는 것: 홈 하단 메뉴(`MapHomeBottomBarMetrics`, `MapHomeBottomBar.swift`와 하단 막대를 그리는 파일), 홈 기본 배치, 홈 마스코트 크기, 여행 화면의 「여권 잉크」 색(`TravelInk`).

## 1. 조사 방법

`python3 scripts/style-survey.py`(`--detail`을 붙이면 간격·여백·글자 크기 분포까지)가 `TaptionPlan/UI`의 Swift 파일을 이름 앞머리로 묶어 숫자를 직접 쓴 곳을 센다. 캔버스에 그리는 아이콘·영상 렌더링의 `cornerRadius:`도 함께 세므로 화면 모서리만의 수는 이보다 조금 적다.

## 4. 이번에 바꾼 것

- 값이 같은 `RoundedRectangle(cornerRadius: 8·12·16·24)` 41곳을 `TaptionCorner.small·medium·large·sheet`로 바꿨다. 화면은 달라지지 않는다. 묶음: 여행(`TravelQuickEntrySheet` 5, `TripImportSheet` 3, `TravelPlanTable` 2, `TravelMapVideoSection` 2), 홈 시트(`MapHome*` 14개 파일 26), 그 밖(`GPXExportCard` 2, `SettingsView` 1, `AppShellView` 1).
- 바꾼 뒤 수치: 여행 16곳·5종, 홈 지도 116곳·18종, 그 밖 31곳. 남은 것은 모두 네 단계 밖 값이거나 위 2번이다.
- 영상에 그리는 `UIBezierPath(roundedRect:cornerRadius:)`와 캔버스 아이콘 안의 값은 화면 모서리가 아니라서 그대로 뒀다.

## 5. 대표에게 물을 것 (객관식 초안)

눈에 띄게 달라지는 변경이라 바로 하지 않았다. 각 물음은 고른 화면 두세 곳의 「전 → 후」 사진을 붙여 묻는다.

1. **사이 값 모서리(9·10·11·13·14·18·20)를 네 단계로 모을까요?**
   - (가) 가까운 단계로 모두 모은다: 9·10·11 → 12(카드) 또는 8(칩), 13·14 → 12, 18·20 → 16 (권함)
   - (나) 지도 위에 떠 있는 것만 모으고 시트 안은 그대로
   - (다) 지금대로 둔다
2. **여행 화면 단추 높이를 앱 규칙(44·40·32)에 맞출까요?**
   - (가) 주 단추 44, 둥근 단추 40, 칩 32 세 가지로 모은다 (권함)
   - (나) 누르는 영역만 44로 넓히고 보이는 크기는 그대로
   - (다) 지금대로 둔다
3. **테두리 굵기를 하나로 맞출까요?**
   - (가) 판·카드는 `TaptionBorder.width` 하나, 고른 것 강조만 1.5 (권함)
   - (나) 여행 화면만 맞춘다
   - (다) 지금대로 둔다
4. **옛 이름 `TaptionRadius`(7~14)를 없애고 `TaptionCorner`로 옮길까요?** (물음 1에서 (가)를 고르면 함께 한다)
   - (가) 옮긴다 (나) 새 화면에만 `TaptionCorner`를 쓰고 옛 화면은 둔다
