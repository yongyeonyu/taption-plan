## 2. DB 형식·경량화·GPS 로그 공유

### 지금 형식
- 파일은 `taption-store.sqlite`(센서·계획·기록)와 `taption-memos.sqlite` 둘이다. WAL, `auto_vacuum=INCREMENTAL`, `secure_delete=ON`(`TaptionStoreV2.swift:1021-1025`).
- `readings`: 센서 표본 한 줄에 한 행, 타입 있는 열 57개 + `extra`(JSON 글자). **압축하지 않는다.** 색인은 `ts` 하나.
- `records`: 계획·실제 기록·메모·가계부·건강 표본 등. `body`가 **압축 안 한 JSON 글자**다.
- `raw_events`: 기기·Watch 원본 묶음. 압축 안 한 JSON.
- `sealed_days`: 닫힌 하루의 요약. **이 표만 LZFSE 압축**이고, 경로는 이미 단순화(Douglas–Peucker)와 1e-7° 정수 차분을 쓴다.
- 백업: 달마다 한 파일(`yyyy-MM.taptionbackup`), JSON Lines → 4MiB 조각 → LZFSE 또는 zlib(작은 쪽) → AES-256-GCM. 건강 표본은 백업에서 뺀다.
- 수치(합성 자료, `docs/DATA_PIPELINE.md`): 표본 한 행 499.4바이트, 1분 간격 1년이면 250.3MB. 실제 기기에서는 `records` 1,284,890행 중 97.9%가 `healthkit-sample`이었다. **실제 기기의 표별 크기와 압축률은 어디에도 재 둔 것이 없다.**
- 이미 끝난 것: P0(품질 계수), P1(JSON 두 번 읽기 제거), P2(열별 비용 제거, 읽기 134 → 37ms). 하지 않기로 한 것: 색인 추가, PRAGMA 조정.

### GPS 로그만 다른 앱과 호환되게
- 지금 있는 내보내기는 전체 JSON과 이틀 치 원본뿐이고, 둘 다 위치 말고도 활동·건강·메모가 섞여 있다. GPX·KML·GeoJSON은 없다.
- **제안 2-8 (바로)**: 위치 점만 담은 **GPX 1.1** 파일을 만들어 공유한다.
  - GPX는 Strava·가민·구글 어스·OsmAnd·GPX 뷰어 대부분이 읽는다.
  - 담는 것: 위도·경도·고도·시각뿐. 활동 이름, 수단, 역 이름, 와이파이, 건강, 가계부, 메모는 넣지 않는다.
  - 기록이 5분 넘게 끊기면 구간(`<trkseg>`)을 나눈다.
  - 자료는 이미 있는 `archivedRouteReadings(in:)`가 시간 순서로 준다. 기기 밖으로 옮겨진 옛 달은 기기에 없어 나오지 않는다.
  - 들어가는 곳: 설정 › 「데이터와 개인정보」의 기존 내보내기 줄 옆.
- 두 번째 형식으로 GeoJSON을 더할지는 쓰임을 보고 정한다(결정).

## 7. UX 시나리오

여섯 가지 흐름을 코드로 따라가며 걸리는 곳을 적었다. 기존 진단(`docs/CLIENT_REPORT.md`, `docs/UX_ARCHITECTURE.md`)과 견줘 [해결]·[부분]·[미해결]을 표시했다.

### 7-1. 첫 실행
- 튜토리얼 21단계 안에 권한 단계가 있다. 「모두 허용」은 시스템 창을 최대 6개 연달아 띄우고, 전부 허용이 아니면 설정 앱을 연다.
- 「닫기」는 묻지 않고 튜토리얼 전체를 건너뛴다. 진행 점은 지금 장만 보이고 전체 몇 단계 중 어디인지는 안 보인다.
- 앱을 열 때 묻는 질문(내 차 → 탑승 → 일정 분류 → 자주 가는 곳 → 미확인)이 **상한 없이 이어지고**, 「나중에」가 기억되지 않아 앱을 새로 켤 때마다 다시 뜬다.
- 개선: 한 번 열 때 질문 하나만, 「나중에」는 그날 동안 기억, 설정 앱 자동 열기 없애기. → 결정(질문 정책은 대표가 정한 순서라 확인이 필요).
- 기존 진단: 늦게 뜨는 권한 창 [해결], 창 겹침 [부분].

### 7-2. 출근 기록 고치기
- 사이드바 두 번 누르기 → 클립 편집 → 분류 → 고르기 → 적용으로 최소 5번 누른다.
- 자동 기록과 직접 넣은 기록이 같은 색이다. 「닫기」가 묻지 않고 편집을 버린다. 적용한 뒤 되돌리기가 화면에 없다(코드에는 `undoLastUserEdit`이 있지만 시험에서만 부른다).
- 개선: 적용 뒤 「되돌리기」 알림 띠, 자동 기록에 작은 표식. → 바로(되돌리기는 기기 확인 뒤).
- 기존 진단: 수정 경로 깊이 [해결], 이름 없는 아이콘 [미해결].

### 7-3. 메모 금액 → 가계부
- 메모 첫 줄만 읽는다. 「1200엔」이 1,200원이 된다(엔·¥·€·달러를 모름).
- 가계부에서 고친 값이 메모를 다시 저장하면 덮어써진다. 밀어서 지울 때 확인이 없다.
- 빈 화면 문구가 두 곳에서 다르다. 가계부로 가는 길이 길게 누르기 뒤에 숨어 있다.
- 개선: 외화 단위 읽기(바로), 가계부에서 고친 값 지키기(바로), 빈 화면 문구 통일(바로).

### 7-4. 미확인 시간 정하기
- `?` → 분류로 2번에 끝난다. 여러 개 한 번에 정하는 창도 있다.
- 되돌리기가 없다. 한꺼번에 → 검토 → 편집기로 창이 세 겹 쌓인다. 한꺼번에 창의 칩이 36pt라 누르기 작다.
- 개선: 칩 44pt(바로), 되돌리기 알림 띠(7-2와 함께).
- 기존 진단: 칩 높이 [부분], 7.9pt 글자 [미해결].

### 7-5. AI로 여행 계획 가져오기
- 여행 모드 → 추가 → 「AI로 만들기」 → 복사 → 붙여넣기 → 같은 화면 아래 미리보기 → 반영.
- 반영을 되돌릴 수 없고 여행 전체를 지우는 길이 없다. 시트에 닫기 단추가 없다. JSON 오류가 회색 보조 글자라 눈에 안 띈다. 미리보기로 저절로 내려가지 않는다.
- 개선: 오류를 경고색으로(바로), 미리보기로 자동 이동(바로), 여행 전체 지우기(결정).
- 기존 진단: 창 위의 창 [미해결].

### 7-6. 백업과 복원
- 메뉴 → 설정 → 데이터 보호. 비밀번호 두 번 입력, 목록은 비밀번호를 넣은 뒤에 보인다. 달 단위로 복원한다.

- 개선: 비밀번호를 정하는 자리에 경고 한 줄(바로), 오류를 그 단추 가까이에(바로), 카드 순서(결정).

## 8. 영수증·캡처·알림·문자 자동 가계부

### 지금 흐름
- **문자·앱 알림**(단축어 자동화) → 결제 후보인지 거름 → 읽기(금액·시각·가게·카드) → 10분 안 같은 금액은 한 번만 → 저장 → 연결된 AI가 가게 이름·분류를 다듬음. 후보가 아니면 저장도 AI 전송도 하지 않는다.
- **붙여넣기·영수증 사진**(가계부 화면)은 입력 화면을 채워 주고 사용자가 확인한다. 단축어의 영수증 동작은 확인 없이 바로 저장한다.
- **스크린샷**은 전용 길이 없다. 사진을 고르면 영수증 규칙으로만 읽는다.
- **메모 금액**(「커피 4500」), **AI 명령**, **같은 길 통행료**가 따로 들어온다.

### 코드를 읽어 확인한 빈틈
가상의 문자 10개를 코드로 따라가 본 결과다(실제 카드사 문자 형식은 확인하지 못했다).
1. 가게 이름이 카드사 이름으로 시작하면 버려진다: 롯데마트·하나로마트·현대백화점·삼성전자서비스 → 제목이 「삼성카드」가 되고 분류는 기타.
2. 카드 이름을 글 전체에서 찾아서, 「롯데카드 승인 … 삼성전자서비스」가 삼성카드로, 「이삭토스트」가 토스카드로 잡힌다.
3. 「승인거절 … 잔액부족」이 지출로 저장된다.
4. 은행의 「카드 결제대금 출금」이 지출로 저장돼 카드 승인과 두 번 계산된다.
5. 「원조국밥 9,000원」에서 시각 `12:30` 뒤의 「30 원」이 먼저 맞아 30원이 된다. 「GS25 원효로점」은 가게 이름이 깨진다.
6. 한 줄짜리 앱 알림은 가게 이름을 못 잡는다(줄 전체가 잡음 낱말에 걸림).
7. 「12.50 USD」처럼 숫자가 앞에 오는 외화, 날짜 없는 시각(「12:31」), 「11월10일」을 못 읽는다.
8. 급여·환급 같은 입금은 버려진다. 자기 계좌 이체·충전은 지출로 들어간다.
9. 취소는 수입으로 들어가고 원래 결제와 이어지지 않는다.
10. 중복 판정이 문자·알림끼리만 본다. 메모 「커피 4500」과 같은 결제 문자는 두 번 들어간다. 반대로 10분 안 같은 금액의 진짜 두 결제는 둘째가 조용히 사라진다.
11. 붙여넣기와 영수증 동작은 결제 후보가 아닌 글도 AI에 보낸다. 「결제 아닌 글은 AI에 보내지 않는다」는 결정과 어긋난다.
