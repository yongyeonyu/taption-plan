## 안 고침 — 이유와 함께 다른 후보 (심각도)
**패키지·서버 방**: 키 교체 직후 따라잡기가 끊기면 새 키를 못 저장(중간~높음, 흐름이 커서 따로), 위치 행 실삭제 알람(중간), 키 교체 `room` 방송에 `locWindow` 누락(중간), 키 교체 뒤 날 묶음 이름 불일치(중간~낮음), `confirmRotation`이 연결 고리를 다시 안 시작(낮음~중간), 메모 바이트 한도(낮음~중간), 가짜 서버가 실제와 다름, `ShareErrorCode`에 `loc_closed`·`loc_rate` 없음, 잠금 연장이 상태 흔들림 뒤 멈춤.
**앱 공유**: 공유 시작 때 기존 「다 같이」 지출이 나만으로 바뀜(의도 확인 필요), 나간 참여자가 낀 지출 수정 불가·`m3` 표시, 곁 파일 한 칸 손상 시 연결까지 잃음, 내 카드 다시 올리기가 사실상 안 돎(`TripShareHost.swift:151-156`), 키체인 저장이 지우고 더하는 순서, `open`/`close`·`forget`·저장 Task 경쟁, 공유 판에서 연 방이 닫히지 않음, 20개 넘는 세부 일정은 잠금 한도, 계획표 잠금 배지·가계부 투영의 성능.
**여행 모드**: 앱에서 만든 여행에 `timeZoneID`가 없어 손으로 넣은 일정이 기기 시간대로 저장됨(**높음**, 나라별 대표 시간대를 정해야 해서 따로), 오늘 카드가 전날부터 이어진 숙소·잠을 「지금」으로 띄움, 칸에서 「지출 넣기」의 시각이 지금 오프셋, 여행 화면 본문이 계획표 모델을 약 20번 새로 만듦, 열 편집 인덱스, 동선 정리가 겹친 일정에서 고정 일정을 넘을 수 있음, 보간이 든 `runtimeText` 번역 누락(여러 파일, 번역 작업이 따로 필요), 접근성 작은 단추.
**지도·사진·영상**: 날짜 변경선·극지방, 사진 가게의 주 스레드 디코딩·메모리 상한, 영상 그리기 주 스레드, 응답 크기 제한 시점, 공용 URL 캐시, 알림 관찰자 중복.
