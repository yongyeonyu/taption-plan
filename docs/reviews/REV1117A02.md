## 대표 결정(2026-11-17, 객관식으로 물음)

1. `/activity` 자유 글의 전화·카드 번호 → **보내는 사본만 가림**(원문은 그대로).
2. 공유 수준 「끔」·개인정보 잠금 때 AI 일 목록·메모 다듬기 → **멈추고 서버 사본 지움**.
3. 공통 규칙 「누가 보냈는지 적지 않아요」와 후보 지문 → **문구를 고침**(지문은 그대로).
4. AI가 사용자 규칙을 켜고 끄기(`set_rule_enabled`) → **지금처럼 둠**.

## 서버 배포

`shared.js`(후보 최소 기기 수), `actions.js`(여행 id·날짜), `validate.js`(날짜), `state.js`·`store.js`·`index.js`(`DELETE /tasks?all=1`)가 바뀌었다. 앱 결정 2는 새 서버가 있어야 열린 일까지 지운다(옛 서버는 `all`을 무시하고 끝난 일만 지움). 옛 요청 형식은 그대로 받는다. 배포는 대표 지시 때만.
