# LGC1117A01 · 꺼진 옛 화면 걷기 (2026-11-17)

대표 지시: 「사용할 만한거 사용하고 나머지는 걷어내」.

## 무엇이 꺼져 있었나

`AppShellView.legacyUIEnabled = false`(7행) 때문에 아래 진입점은 실제 앱에서 한 번도 열리지 않았습니다.

- 시트 3개: `AddPlanSheet`(일정 추가), `QuickActionSheet`(활동 선택), `PlanEditorSheet`(일정 편집).
- `model.detail` 상세 13가지: `GroupGanttView`·`GoalDetailView`·`ActualRecordDetailView`·`UnconfirmedRecordDetailView`·`LocationTimelineView`·`MemoDetailView`·`InferenceDetailView`·`CatPickerView`·`CategoryManagerView`·`CategorySetupView`·`WidgetPreviewView`.
- 옛 탭 4개: `ScheduleView`(시간표)·`GoalsView`(목표)·`ReviewView`(되돌아보기)·`SettingsView`(설정).

## 어떻게 골랐나

앱·위젯·Watch·Watch 위젯 네 폴더의 Swift 최상위 선언을 타입 단위로 읽어 도달성을 셈했습니다.

- 뿌리: `@main` 앱, 위젯·Watch 폴더 전부, 앱 의도·위젯·Live Activity·앱 대리자처럼 시스템이 부르는 타입, 이미 있는 타입이 아닌 것(`View`·`String` 등)에 붙인 extension, 최상위 함수·값.
- 분기를 걷기 전(HEAD)과 뒤를 같은 방법으로 세어, **뒤에만 닿지 않는 타입**을 옛 화면 몫으로 봤습니다. 둘 다 닿지 않는 타입(원래부터 죽은 코드)은 이번 범위가 아니라 후보로 남겼습니다.
- `#Preview`는 뿌리로 치지 않았습니다(옛 화면을 미리보기만 붙잡고 있었음).
- 지운 뒤 다시 세어 새로 닿지 않게 된 타입이 0개임을 확인했습니다. 모자란 판정은 빌드가 잡습니다.

결과: 처음 짐작(약 9천 줄)보다 큽니다. 옛 시간표가 `TimelineBoard`·`TimelineDetailPanel`·`ScheduleTimelineCaches`·`TimelineInteractionEngine`과 되돌아보기 시계·차트 엔진을 끌고 있었기 때문입니다.

## 남은 후보(옮기지 않은 것)

큰 새 화면 작업이 되거나 판단이 필요한 것입니다. 코드는 git 이력(이 브랜치의 바로 전 커밋)에서 되살릴 수 있습니다.

1. **목표 반복 규칙 편집**(`GoalRepeatRulesEditor`): 지금 화면에서는 AI 명령으로만 반복 규칙을 바꿀 수 있습니다. 화면으로 살린다면 `docs/reviews/REV1117A04.md`의 인덱스 삭제 결함(목록을 돌며 지운 뒤 같은 인덱스를 다시 씀)을 함께 고쳐야 합니다.
2. **되돌아보기 통계·하루 시계**(`ReviewView`·`RecordChartEngine`·`RecordClockEngine` 고리 부분): 기간별 막대·원형 시계·재생은 지금 화면에 없음. 새 화면 규모.
3. **옛 시간표 간트**(`TimelineBoard`): 지도 홈의 NLE 편집기가 대신함. 주·월 간트 보기가 필요하면 새 설계로.
4. **동작 줄이기 켜고 끄기**: 지금은 AI 명령으로만 바꿈. 메뉴 › 표시에 한 줄 더하면 되지만 홈 메뉴 배치가 바뀌므로 대표 판단.
5. **HealthKit 전체 다시 맞추기 단추**: 켤 때 자동으로 돌아 지금은 필요 없어 보임.
6. **센서 추정 근거 화면**(`InferenceDetailView`)·**위치 시간선**(`LocationTimelineView`): 개발·진단용. 지도 홈의 원본 상세(`MapHomeNLERawDetail`)가 일부를 대신함.
7. **`AppModel`의 옛 탐색 상태**(`detail`·`selectedTab`·`isAddPlanPresented`·`selectedAction`·`planEditorRequest`·`openInitialSetup`): 딥링크·바로가기 경로가 아직 값을 쓰므로 이번에는 두었습니다. 지도 홈 경로로 모두 옮겨졌는지 확인한 뒤 걷을 후보.
8. **원래부터 닿지 않던 코드**(분기와 무관, HEAD에서도 닿지 않음, 약 1,700줄): `MapHomeTripPlanSheet`·`TravelTripSchedule`·`TravelPlanBand`·`TravelWishFooter`·`TripItemStatusPicker`·`TripUnpinnedItemStatusList`·`LedgerDayCards`·`MapHomeCalendarButton`·`MapHomeTodoButton`·`MapHomeLocationButtonIcon/State`·`MapHomePanGestureObserver`·`MapHomePlaceBookVisitPolicy`·`NLESensorEvidenceText`·`NLESensorLabelPlacement`·`RecordRelationshipEngine` 묶음·`PlanBackupRouteFallbackEngine`·`RequiredPermissionGateView`·`SensorCollectionWaveformMath`·`TaptionWidgetPayloadSyncPolicy`·`TripShareMemorySecrets`·`WatchSensorDrainLedger`·`CatMotionPolicy`, 시험에서만 쓰는 `InMemoryPlanRepository`·`InMemoryPlanCredentialStore`·`MockPlanLocalBiometricAuthenticator`·`PlanItem`(SwiftData `@Model`이라 저장 형식을 건드리지 않으려고 `PlanCategory`와 함께 그대로 둠). 일부는 RFT1116A02가 이미 후보로 적음.
