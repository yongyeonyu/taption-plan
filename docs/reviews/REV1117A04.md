# REV1117A04 · 가계부·결제 문자·설정·목표·메모·일정·첫 실행·위젯·Watch 리뷰 (2026-11-17)

읽은 범위: 맡은 파일 전체(코어 직접 정독, 위젯·Watch·설정 UI는 읽기 전용 하위 에이전트 보고를 코드로 일부 재확인). 설정·일정·목표 화면 다수는 `AppShellView.legacyUIEnabled = false`라 실제 앱에서 열리지 않음.

| Medium | 위젯 미리보기 「종료」가 시작 전 계획을 완료 처리 | 실행 중일 때만 표시 |

## 안 고친 것 (이유)
- Medium(위젯): 열린 자동 기록 막대가 위젯에서 멈춤, 개인정보 잠금 중에도 잠금 화면에 연봉 카운터, 실행 중 계획을 고쳐도 Live Activity 안 바뀜(`update(plan:)` 호출 없음), 잠금 화면 「종료」가 `LiveActivityIntent`가 아님 — 앱 Live Activity 코드·실기기 확인 필요, 범위 큼.
- Medium(Watch): 원본 재생성 O(창×표본) 폭증(2시간 운동), 운동 요약·가속도 묶음 재전송 길 없음, 백그라운드 새로고침 25초 예산 미준수, 주변 기록 ack 전 재전송, 「맞아요」 응답 조용한 유실 — 구조 변경.
