## 조심할 것

- 같은 작업 트리를 「taption wbs 폴더 읽기」(여행 모드)와 또 다른 메인개발 fork(단축어)가 함께 쓴다. 자기 파일만 스테이징하고, 푸시 전 `git log origin/main..HEAD`로 남의 커밋이 섞이는지 본다.
- 319 커밋(f66220bb)에 Live Activity PNG 삭제가 섞여 들어갔다(바로 다음 커밋에서 SVG 추가로 맞춤).
- `scripts/l10n/source.json`·`TaptionPlan/UIText.xcstrings`에는 4aa45f58 시점의 여행 화면 문구가 영어만 있는 상태로 들어 있다.
- 벡터 SVG는 기본 크기(width·height)가 구워지는 비트맵 크기를 정한다. 1024로 두면 오히려 커진다.
- 단축어의 영수증 동작(`SiriIntents.swift`)은 예전 영수증 규칙 그대로 한 건만 넣는다.
- 시뮬레이터 화면 누르기는 여전히 안 된다(접근 요청 미응답). Debug 전용 실행 인자로만 화면을 띄울 수 있다.
