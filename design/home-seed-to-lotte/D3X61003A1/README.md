# 3일마다 다른 세계 건축 · 366장

총 366장을 122종 × 3일로 다시 만들었습니다. 씨앗·새싹·묘목·큰 나무·모닥불·동굴·해먹·움막·유르트·수상 움막의 10단계 뒤, 세계 건축 112종이 대표 시기순으로 이어집니다. D364–D366은 롯데월드타워입니다. 이전 53단계와 356/366장 시안은 보존했습니다.

같은 단계의 3일도 따로 그렸습니다. 주요 지붕, 탑, 열주, 성문, 건물 동, 테라스, 캡슐, 외피, 정원 등이 바뀝니다. 모든 단계에 같은 별채를 붙이는 구성에서 벗어나, 피라미드·빙고·원형극장·스투파·암벽 신전·사원·성곽·한옥·토루·트룰리·풍차·온실·경기장·곡면 건물·쌍둥이 타워 등 본체 형태가 3일마다 달라지게 배치했습니다. 색이나 날짜만 바꾼 복제·crossfade는 사용하지 않았습니다.

- `daily/`: 날짜별 투명 PNG 512×512 366장 및 편집 가능한 SVG 366장. 아이콘 안에는 날짜·숫자를 넣지 않았습니다.
- `daily-366-three-day-png.zip`: 실제 PNG 366장, 날짜 슬라이더와 3일 비교를 제공하는 오프라인 `index.html`, 전체 미리보기·CSV·JSON·이 문서.
- `daily-366-three-day-svg.zip`: 실제 SVG 366장과 제작 소스. PNG와 미리보기는 PNG 묶음에 있습니다.
- `contact-sheet-128.png` / `contact-sheet-48.png`: 저장소에서 별도로 제공하는 122종의 각 3일차 미리보기. PNG ZIP에는 같은 전체 미리보기를 `index.html` 안에 포함하여 PNG 파일 수를 정확히 366개로 유지했습니다.
- `review/`: 전체 366장을 3일씩 나란히 확인할 수 있는 11개 페이지. 128px/48px 두 크기로 제공됩니다.
- `days.csv` / `manifest.json`: D001–D366의 건축 단계, 지역, 대표 시기, 일별 변화와 파일 매핑.

PNG 압축을 푼 뒤 `index.html`을 브라우저에서 열면 인터넷 연결 없이 366장과 122단계를 선택할 수 있습니다. 파일명 D001은 첫 성장일을 뜻하며, 앱의 실제 달력 날짜 선택 정책은 아직 연결하지 않았습니다. 365일 구성에서의 마지막 날 정책도 앱 적용 때 별도로 정해야 합니다.

검증은 SVG XML, PNG 수량·고유성·RGBA·크기·투명 배경·캔버스 경계, 연속 366일 매핑, 각 단계의 정확한 3일 배분, 대표 시기의 비감소 순서, 48px의 매일 변화와 건물 전환 차이를 확인했습니다. 전체 일별 검토 페이지도 시각 확인했습니다. 최종 수치와 실행 근거는 저장소의 `build/validation/D3X61003A1/` 및 `test.md`에 있습니다. 픽셀 비교와 제작 화면 검수는 실제 기기에서 사용자가 느끼는 변화의 통과 판정을 대신하지 않습니다.

양식·랜드마크의 특징을 단순화한 창작 RPG 벡터입니다. 전통 양식의 연도는 선정한 대표 시기이며 최초 등장 연도가 아닙니다. 천단은 1420년 단지 기준이며 그림의 기년전 형태 전체가 그때 완성됐다는 뜻은 아닙니다. 낙수장은 1939년 부속 건물까지의 구성, 마리나베이샌즈는 설계사 자료의 2011년, 상하이타워는 2015년 설계사/준공 자료 기준입니다. 같은 해는 월·일까지의 순서를 주장하지 않으며 끝은 롯데월드타워로 정했습니다. 일별 증축은 게임 표현이고 실제 건물을 정확하게 복원한 도면이 아닙니다. 확인한 주요 자료는 [references.md](references.md)에 있습니다.

현재는 이미지와 일별 매핑 제작 완료입니다. 기존 앱 코드와 `Assets.xcassets`에는 이 세트를 넣지 않았으며, 새 이미지의 앱 자동 교체·설치·실기기 화면 검증은 수행하지 않았습니다.
