# 세계 건축 연대순 · v5

53주 기준 이미지. 1–7주는 씨앗·나무·야영이라는 비연대 도입입니다. 해먹이나 움막의 역사적 최초 등장 순서를 주장하지 않습니다. 8–53주는 선택한 대표 건축/시기의 대략적인 연대순입니다. 특정 양식의 최초 발명 연도나 한 나라가 다음 나라보다 발전했다는 의미가 아닙니다. 지역 양식은 공존합니다.

전통 주거뿐 아니라 신전·궁전·성곽·박물관 등도 포함한 세계 건축 아이콘입니다. 역사 재현이나 실제 건물의 정밀 축소도가 아니라 특징을 단순화한 창작 벡터입니다. 일부 양식의 대표 세기 선택은 디자인 편집 기준이고 모든53단계의 정확한 연대가 학술 검증된 것은 아닙니다.
