# Taption Plan

계획과 실제 활동을 시간표와 지도에서 함께 확인하는 SwiftUI iPhone/iPad 앱입니다. Apple Watch, HealthKit, 위젯, iCloud 암호화 백업을 포함합니다.

- 프로젝트: `TaptionPlan.xcodeproj`
- 스킴: `TaptionPlan`, `TaptionPlanWatch`
- 최소 OS: iOS/iPadOS 18, watchOS 11
- 저장: SQLite 정본과 일자 projection, Swift Package 엔진
