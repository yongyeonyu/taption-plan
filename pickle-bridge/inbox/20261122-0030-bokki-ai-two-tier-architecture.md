## 1. 목적 및 배경

현재 외부 에이전트(피클 등)가 `trip-relay`를 통해 처리하는 비서 기능을, **외부 AI를 연결하지 않은 일반 앱 사용자도 앱 자체 내장 AI("복희 AI")로 바로 쓸 수 있도록** 서버 + 온디바이스 2단 하이브리드 구조로 통합한다.

### 포함 기능 범위
1. **자동 분류·교정**: 이동 수단 오분류 교정(`route_check`), 결제 문자 가계부 분류(`payment_text`), 활동 자동 구분
2. **능동 비서 기능**: 시간대별 맞춤 말풍선, 일정·리마인드 제안 및 자동 등록
3. **음성 인터랙션**: 음성으로 메모 입력, 음성으로 기존 활동/일정 수정

---

## 2. 2단 하이브리드 처리 구조 (비용 최소화)

### 1단: 온디바이스 우선 처리 (서버 비용 0원)
- **대상**: Apple Intelligence(Foundation Models) 지원 기기 + 로컬 휴리스틱 규칙
- **처리 항목**:
  - 집/직장 반경 내 짧은 GPS 튐(자택 내 차량 오분류 등) 로컬 판정
  - 뻔한 결제 문자 키워드/패턴 1차 분류
  - iOS 온디바이스 음성 인식(`SpeechTranscriber` / 받아쓰기)으로 음성 메모 텍스트화
  - 단순 메모 다듬기 및 기본 일정/활동 구분
- **장점**: 서버 과금 0원, 오프라인·실시간 응답, 위치·문자 데이터의 외부 전송 최소화

### 2단: 자체 서버 AI (`trip.bokkiyaw.com`, 크레딧/저비용 모델)
- **호출 조건**: 온디바이스 미지원 기기이거나, 1단 신뢰도가 낮은 복합 요청(예: `동아웰빙타운관리단` 같은 모호한 가맹점 추론, 복합 음성 수정 명령, 맥락 기반 말풍선 생성)
- **백엔드**: AWS Bedrock(우선, $1,000 크레딧) + Azure OpenAI(보조/이중화, $200~$5,000 크레딧)
- **모델 전략**: 단순 분류·정형 JSON 추출은 초저가/경량 모델(Haiku / Nova Micro·Lite 등)로 고정해 건당 원가를 1원 미만~1원대로 유지

## 3. 무료(Free) vs 유료(Pro) 쿼터 및 제한 설계 (제안)

무료 사용자는 서버 원가를 거의 0원으로 묶으면서도 앱의 핵심 가치를 체감해야 하고, 유료 사용자는 무제한 남용(봇/과도 호출)으로 적자가 나지 않도록 공정 사용량 상한(Fair Use Cap)을 둔다.

| 구분 | Free (무료 사용자) | Pro (유료 구독) |
|---|---|---|
| **1단 온디바이스 AI** | 무제한 (서버 원가 0원) | 무제한 (서버 원가 0원) |
| **2단 서버 AI (텍스트/분류)** | **일 3~5회 (월 최대 30회)** 체험 | **일 50회 / 월 1,000회** (공정 상한) |
| **이동·문자 백그라운드 자동 교정** | 로컬 규칙만 자동, 서버 AI는 수동 탭 시 호출 | 2단 하이브리드 **백그라운드 자동 실행** |
| **음성 메모 입력** | 온디바이스 STT 무제한 | 온디바이스 STT + 서버 AI 복합 파싱/수정 포함 |
| **유료 음성 (Cartesia TTS / 클라우드 STT)** | 미제공 (iOS 기본 TTS 사용) | **월 60분** 상한 (또는 별도 크레딧) |
| **한도 초과 시 동작** | 온디바이스/수동 입력 폴백 + Pro 안내 | 당일/당월 클라우드 2단 중단 후 1단 온디바이스 폴백 |

### 원가 방어 계산 근거
- 경량 모델 기준 1회 분류(입력 ~1,000토큰, 출력 ~300토큰) 원가: 약 `$0.0005 ~ $0.001` (약 0.7~1.4원)
- Pro 유저가 월 1,000회를 꽉 채워 사용해도 텍스트 AI 서버 원가는 **월 ~1,000~1,500원** 수준에서 안정적으로 방어됨.

## 4. 구현 시 체크포인트 (`taption-plan`)

1. **D1 사용량/쿼터 테이블 추가**: `user_id` 기준 `daily_cloud_ai_count`, `monthly_cloud_ai_count`, `monthly_voice_sec` 추적 및 플랜(`free` / `pro`)별 게이트 체크
2. **단일 게이트웨이 응답 규격**: 서버 한도 초과 시 `429 quota_exceeded`와 `fallback: "on_device"`를 반환해 앱이 멈추지 않고 자연스럽게 온디바이스로 넘어가도록 처리
3. **기존 외부 에이전트(피클) 경로와 공존**: 외부 에이전트(`/tasks/claim`, `/command`)는 사용자 본인 연결 세션으로 유지하고, 앱 내 자체 AI 경로와 충돌·중복 실행되지 않도록 `source: "built_in_ai" | "external_agent"` 구분
